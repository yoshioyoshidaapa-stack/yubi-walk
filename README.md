# ゆびウォーク (yubi-walk)

人差し指と中指を足に見立てて、スマホの画面をトコトコ歩かせて進む3Dアクションゲームの試作です。

## 今の状態

操作感を確かめるための最小の試作です（100mの直線、ハードル4つ、タイム計測）。

- 歩く: 「左足」「右足」の枠に指を置いて手前（画面の下のほう）へ引く。左右交互に。長く・速く引くほど速く進む
- ジャンプ: 2本とも置いてから、そろえてパッと離す
- タップしただけでは進まない。同じ側の足を2回続けても進まない（明るい枠が次に出す足）
- パソコンでは F キーと J キーを交互に、スペースでジャンプ

## 遊び方

`index.html` をブラウザで開くだけで動きます（3D表示の部品 three.js をインターネットから読み込むので通信が必要です）。

## 予定

- Android 向けに一般公開する
- 視点はキャラクターのやや後方・上から見下ろす3D

## ファイル

- `index.html` … ゲーム本体（画面・見た目・動きがすべてこの1ファイルに入っています）。
  冒頭近くの「tuning」と書かれた部分の数字で、進む速さやジャンプの高さを調整できます。
