# ゆびウォーク (yubi-walk)

人差し指と中指を足に見立てて、スマホの画面をトコトコ歩かせ、逃げ回るサルを捕まえる3Dアクションゲームの試作です。

## 今の状態

操作感を確かめるための試作です。広場を逃げ回るサルを5匹、ぜんぶ捕まえるまでのタイムを計ります。

- 歩く: 「左足」「右足」の枠に指を置いて手前（画面の下のほう）へ引く。左右交互に。長く・速く引くほど速く進む
- 曲がる: ななめに引く。右ななめ手前に引くと左へ、左ななめ手前に引くと右へ曲がる（画面左下のボタンで逆にできる）
- ジャンプ: 2本とも置いてから、そろえてパッと離す。丸太をとびこえる
- タップしただけでは進まない。同じ側の足を2回続けても進まない（明るい枠が次に出す足）
- 捕まえる: サルにさわると捕まえられる。近づくと逃げるが、追い続けると疲れて遅くなる。柵に追いつめることもできる
- 画面上の ▲ がいちばん近いサルの方向、数字が距離
- パソコンでは F・J キーを交互に、A・D キーで曲がる、スペースでジャンプ

## 遊び方

`index.html` をブラウザで開くだけで動きます（3D表示の部品 three.js をインターネットから読み込むので通信が必要です）。

## 予定

- Android 向けに一般公開する
- 視点はキャラクターのやや後方・上から見下ろす3D
